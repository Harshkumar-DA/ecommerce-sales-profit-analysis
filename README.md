# E-COMMERCE SALES & PROFIT ANALYSIS

## Project Overview

This project analyzes e-commerce sales data using SQL and Microsoft Power BI to understand sales performance, profitability, customer segments, product performance, and order status.

## Tools Used

* **SQL (MySQL):** Data analysis and business queries
* **Microsoft Power BI:** Interactive dashboard and data visualization
* **Microsoft Excel / CSV:** Dataset handling

## Dataset

The dataset contains 1,000 e-commerce order records with information about:

* Order date and order ID
* City and customer segment
* Product and category
* Quantity, unit price, and discount
* Sales, cost, and profit
* Payment mode and order status

**Dataset file:** `Ecommerce_Sales_Analytics_1000_Rows.csv`

## SQL Business Questions

The analysis covers:

1. Total orders and revenue
2. Average order value
3. Category-wise sales and profit
4. Top-performing products
5. City-wise revenue
6. Customer segment analysis
7. Payment mode analysis
8. Order status distribution
9. Monthly sales trends
10. High-sales and high-profit categories

## Power BI Dashboard

The interactive dashboard includes:

* Total Revenue
* Total Profit
* Total Orders
* Average Order Value
* Sales by Product
* Sales and Profit by Category
* Revenue by City
* Monthly Sales Trend
* Order Status Distribution
* Profit by Customer Segment

## Key Objectives

* Identify top-performing products and categories.
* Compare revenue and profit across cities.
* Analyze monthly sales trends.
* Understand customer segment profitability.
* Monitor delivered, returned, and cancelled orders.
